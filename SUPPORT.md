# Yamabiko Support

For setup and common runtime problems, start with the [installation
guide](README.md#install-yamabiko) and [troubleshooting guide](README.md#fix-common-problems).
If the problem remains, use the appropriate contact:

- User support: [support@kaze.be](mailto:support@kaze.be)
- General and community: [Yamabiko@kaze.be](mailto:Yamabiko@kaze.be)
- Commercial licensing: [licensing@kaze.be](mailto:licensing@kaze.be)

Bug reports are also welcome in the [issue tracker](https://github.com/Yamabiko-ASR/yamabiko/issues).
**Save diagnostics** (left-click the tray icon, then **Troubleshooting**) creates the most useful attachment.

Report vulnerabilities privately using the instructions in the
[security policy](.github/SECURITY.md), not through support email or a public
issue.
