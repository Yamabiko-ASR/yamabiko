# Yamabiko v0.1.0-beta

**Yamabiko (山彦)** is a real-time Japanese→English subtitle overlay for Windows.
It listens to whatever is playing on your PC (a stream, a VOD, a game), and
draws live English subtitles (with optional furigana over the Japanese) on a
translucent overlay on top of it. Audio capture, transcription, and
translation run locally on the PC.

This is the first beta of the core listen → transcribe → translate → display
loop.

---

## What it does

A fully on-device pipeline:

1. **Capture**: taps your default audio output via WASAPI loopback (no
   microphone, no virtual cable needed).
2. **Voice activity**: Silero VAD segments speech from silence.
3. **Transcribe**: `faster-whisper` running `large-v3-turbo` produces
   Japanese text.
4. **Sentence boundaries**: fast-bunkai splits the transcript into complete
   Japanese sentences.
5. **Translate**: a local `llama.cpp` server running **shisa-v2.1-qwen3-8B**
   (a Japanese-tuned model) translates JA→EN.
6. **Display**: a frameless always-on-top overlay renders the English line,
   with stacked furigana over the source when enabled.

A supervisor (watchdog) keeps the pipeline, overlay, and translator alive and
restarts them if they crash.

## Requirements

- **Windows 11** (x64).
- **NVIDIA GPU**, Turing (RTX 20-series / GTX 16-series) or newer, **CUDA 12**.
- Enough VRAM to keep the speech and translation models resident; 12 GB cards
  are the practical baseline for this beta.
- ~10 GB free disk for the app + downloaded models.
- An internet connection **for first-run setup only** (to download the models).

There is no CPU-only or AMD/Intel-GPU path in this release.

---

## Install & first run

1. Download `yamabiko-0.1.0-beta-setup.exe` from the release assets and run it.
2. **SmartScreen:** this beta is **not yet code-signed**, so Windows may show
   "Windows protected your PC." Click **More info → Run anyway**. (Signing is
   planned for a later release.)
3. On first launch, a **setup wizard** walks you through:
   - an audio-capture test,
   - downloading the models (several GB; speed depends on your connection).
4. When setup finishes the overlay starts automatically. Play Japanese audio
   to confirm the selected capture source.

Models are stored under `%LOCALAPPDATA%\Yamabiko\models\` and are kept on
uninstall, so a reinstall can reuse them.

## Known limitations

- **Japanese audio only.** Yamabiko transcribes everything as Japanese, so
  playing **English or other-language** audio produces garbled output: it
  force-transcribes the foreign speech *into* Japanese and then translates that
  back. Point it at Japanese content.
- **Unsigned binary**: expect the SmartScreen prompt above.
- **NVIDIA-only**, Windows 11 only: no CPU / AMD / macOS / Linux support yet.
- Translation quality and latency vary with content; very fast overlapping
  speech is the hardest case.
- First-run model download is large; on a slow connection it takes a while.

---

## Privacy

All audio, transcription, and translation happen **on your machine**. Yamabiko
does not send your audio or text anywhere. The only network access is the
one-time model download during setup (from Hugging Face) and an optional
update check.
